# Практична робота 7
## Мета роботи
Ознайомитися з принципом роботи структури даних «черга» (Queue) за принципом FIFO (First-In, First-Out — першим зайшов, першим вийшов), навчитися створювати чергу цілих чисел у середовищі Visual Studio (C#) та виконувати над нею базові операції: додавання елементів (Enqueue), їх виведення, перегляд та очищення.

## Висновок
Під час виконання практичної роботи було закріплено теоретичні знання та освоєно практичні навички роботи зі структурою даних «черга» (Queue) на основі принципу FIFO (First-In, First-Out). За допомогою середовища Visual Studio та мови програмування C# було успішно створено чергу цілих чисел, а також реалізовано основні операції над нею: додавання елементів (Enqueue), перегляд першого елемента, виведення вмісту у текстове поле (TextBox) та очищення колекції. Набуті навички дають змогу ефективно використовувати черги для вирішення прикладних алгоритмічних завдань і обробки даних у порядку їх надходження.
